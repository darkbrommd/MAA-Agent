# GUI 2.0 最终发布收口清单

本轮目标是把仍需人工指出的界面细节一次收完，完成后应达到可推送最终预览版的状态。默认 Tk、生产 Agent、真实配置和 `app/agent.py` 核心判断不改动。

## 日程管理

- 放弃上下无限扩展：一次只显示一个运行日，左右按钮一次切换一天。
- 运行日默认从 04:00 开始，到次日 03:59 结束；设置中可选择小时和分钟。
- 小时下拉接受 0–24，24 按 0 点保存和使用。
- 切换日期时旧内容保留到新内容准备完成，不显示“正在读取/已加载”技术状态。

## 设置

- 日程开始时间、日报时间都使用“小时 + 分钟”下拉选择，不再手填 `HH:MM`。
- 官网每天检查时间改成可增删列表：`+` 添加一项，每项可选择小时、分钟并可删除。
- 提醒时间和高级检查频率统一使用整数框，不显示小数点；未获焦点时滚轮不得误改。
- MAA 文件夹保留文件夹浏览；MAA 和 MuMu 启动文件都增加浏览按钮，文件选择只显示 `.exe`。

## 通知测试

- 点击通知样例后，该样例成为当前选择。
- “发送以上测试通知”发送当前选择对应的既有诊断命令；没有选择时默认测试 Bark 通道。
- 单 MAA 配置隐藏 MAA2 样例；MAA 未运行测试继续走 Agent 已有的真实检测演习入口。

## 总览与公告

- 总览“事故与恢复 / 全部”使用与其他按钮一致的菜单按钮，不保留突兀的原生下拉框。
- 总览最近记录按可用宽度自动换行。
- 公告更新时间将 ISO 字符串改成 `YYYY年MM月DD日 HH:MM`，不直接展示 `T` 和时区格式。

## 验收

- 运行日边界、24→0、左右切日、时间列表增删和配置往返均有测试。
- 通知样例到诊断命令的映射有测试，不实际发送 Bark。
- 100%、125%、150%、175% 缩放下按钮、时间控件和侧栏不重叠。
- 完整回归、后台零 PySide6 导入、Windows CI 与构建通过后再同步最终结果。

## 最终实现与发布结果（2026-11-28）

- PySide6 GUI 已成为默认桌面入口；旧 Tk GUI 保留为 `--gui-v1` / `MAA_AGENT_GUI=v1` 回退入口。后台 `--maa-agent-background` 仍延迟导入 GUI，不加载 PySide6 Widgets。
- 总览保留 Agent/MAA/MuMu 状态和启停操作，并集中展示内存、按应用汇总的高占用程序、未来计划、最近事件和内存趋势；其他页面移除固定顶栏，让出纵向空间。
- 日程最终采用单运行日视图，不再使用多日瀑布流。默认 04:00 换日，可调整开始时间；顶部/底部提供前后一天入口，卡片继续保留临时开关、改时、状态底色和失败详情。
- 资源页加入日期日历、系统运行时长、自绘趋势图、内存过高记录和进程名/正则白名单；连续相似异常会降低记录频率，页面读取在后台完成。
- 公告页保留左右分栏、选中项和滚动位置，支持增量更新与完整重拉；正文清洗、段落列表和中文时间显示已收口。
- 日志使用增量尾追，支持筛选、搜索、暂停滚底以及 `Ctrl + +/-/0` 和 `Ctrl + 滚轮` 调整字号。
- 设置与首次向导统一为用户可读文案，保留固定保存栏、密钥遮罩、单/双 MAA、时间下拉、路径浏览、通知样例与真实测试映射；主题切换独立保存，不会提交其他草稿。
- 页面 IO、日志、公告、资源历史和进程扫描均放入后台 Worker；日程和异常记录使用 Model/View，资源日期请求带防抖、版本号、签名和 LRU 缓存；托盘隐藏后暂停非必要界面刷新。
- 首次发布包曾遗漏 `dark.qss` / `light.qss`，会在 PyInstaller `_MEI` 目录报 `FileNotFoundError`。问题包已删除并重新发布；构建脚本现在显式打包两个文件，并在生成 EXE 后读取内部归档验证，缺失即构建失败。
- 最终本地完整回归 **214 项通过**，175% GUI 专项 **48 项通过**；打包 EXE 实际启动、主题加载、后台 Agent 状态继承和约 88 MB 工作内存均已验证。
- GitHub `main`、`codex/gui-v2-pyside6` 和标签 `v2.0.0` 均指向远端提交 `a08d2546`，Tree SHA 为 `2ed193a0`。CI `46131841996` 与 Release 工作流 `46131882128` 均成功，正式版本见 <https://github.com/darkbrommd/MAA-Agent/releases/tag/v2.0.0>。
