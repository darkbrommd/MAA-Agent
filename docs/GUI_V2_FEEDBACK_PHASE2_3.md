# GUI 2.0 实机反馈修正说明（Phase 2.3）

本轮处理 2026-11-26 的第三批实机细节反馈。继续在 `codex/gui-v2-pyside6` 分支工作；生产 Agent、默认 Tk 入口、`app/agent.py`、真实配置和网络环境均不修改。

## 本轮范围

1. 总览最近事件区分“用户主动隐藏”和“本来没有事件”：只有主动清空后显示“此前事件已隐藏”，自然空列表显示“最近没有事故、异常或恢复记录”。
2. 修正应用内存 Top 3 对 `svchost.exe` 的错误归并。普通多进程应用继续按可执行文件合计；Windows 服务宿主按 `-s` 服务名拆分，无法识别的宿主不作为一个 84 进程的应用展示。
3. 将总览计划卡片的“关闭本次 / 打开本次”文字按钮改为与日程管理一致的 Toggle 交互，并继续只修改 Agent 监督例外，不修改 MAA 定时器。
4. 优化资源异常采样的详情弹窗：使用结构化指标、分组进程列表和清晰层级，避免大段原始文字；不增加后台采样频率或额外周期扫描。
5. 日志中心支持 `Ctrl + 加号/减号` 与 `Ctrl + 鼠标滚轮` 调整日志字号，并支持 `Ctrl + 0` 恢复默认；不增加常驻按钮。
6. 检查现有公告缓存与解析链，修复正文缺失、导航残留、段落挤在一起和列表格式错乱；保留增量更新及全部重拉的既有语义。
7. 增大左侧“监控中心 / 系统管理”分组间距；提高深色模式下已结束、等待运行、停止监测的区分度；优化失败卡片与错误详情的视觉层级。

## 验收标准

- 空事件提示不会把“本来没有事件”误写成“用户已经隐藏”。
- 多进程浏览器等仍按应用总量统计；`svchost.exe · 84 个进程` 不再出现。
- 总览 Toggle 与日程 Toggle 的状态、动画和失败回滚行为一致。
- 资源详情只在用户双击时整理现有快照，不引入新的周期 IO 或进程扫描。
- 日志字号快捷键不会影响页面缩放或其他输入控件，字号有合理上下限。
- 公告正文保留自然段和列表，清除网站导航/脚本噪声；缺正文时提供明确提示而不是空白。
- 深色四态卡片能仅凭底色、状态条和徽标区分，100%–175% 缩放无文字遮挡。
- 完整回归、175% GUI 专项、后台零 PySide6 导入和远端 Windows CI 通过。

## 实施结果

- 总览自然空列表显示“（最近没有事故、异常或恢复记录）”，只有点击“清空主页显示”后才提示此前事件已隐藏。
- 应用内存继续合并浏览器等多进程应用；`svchost.exe` 改按 `-s` 参数中的服务名拆分，无法识别的服务宿主不进入应用 Top 3。本机实测 Top 3 恢复为 ChatGPT、QQ、Edge WebView，不再出现 84 个服务宿主被视为一个应用。
- 新增共享动画 `ToggleSwitch`，总览计划卡改用与日程相同的开关语义；保存失败会动画回滚。
- 资源异常和任务失败详情改为深浅主题兼容的结构化可滚动对话框；只整理现有采样快照，不产生新 IO 或进程扫描。
- 日志中心支持 `Ctrl + 加号/减号`、`Ctrl + 鼠标滚轮` 和 `Ctrl + 0`，字号限制为 9–24px 并保存在 GUI 页面状态。
- 公告清洗器保留段落和项目符号、恢复常见小节标题并移除官网导航尾；公告页按段落/列表渲染，同时明确显示仍有多少条正文待补。本机旧缓存 50 条可直接清理，首篇由单行恢复为 21 行，导航尾已消失，仍缺正文 3 条。
- 深色主题为等待运行、已结束、停止监测增加独立底色；运行中、下一计划和失败卡片使用状态色边框，失败详情改用信息分区。
- 导航分组间距增大。2026-11-26 本地完整回归 199 项通过，175% GUI 专项 37 项通过，编译检查通过。
