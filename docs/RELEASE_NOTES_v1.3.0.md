# MAA Agent v1.3.0

本版本把日报的可选智能分析升级为通用 AI 接口。

## 更新内容

- 支持自定义 OpenAI Chat Completions 兼容 API 地址、模型和 API Key；
- 设置页可直接完成 AI 接口配置，无需手动编辑 JSON；
- 去除原有供应商专用调用参数，兼容更多 AI 服务；
- 旧版配置继续自动识别，升级后不会突然失效；
- README、操作手册、诊断工具和程序内文案统一改为通用 AI 表述；
- 手动联网诊断脚本更名为 `tools/diagnostics/test_ai.py`。

AI 分析默认关闭。启用后，程序仍会先使用本地规则整理日报，只在出现值得关注的异常或持续资源压力时调用 AI；默认每天最多调用一次。
