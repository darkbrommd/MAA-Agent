# GUI 2.0 标题栏、图标与通知测试收尾

本轮处理实机检查中发现的四个问题，不改变 Agent 的任务判断、告警冷却或网络配置。

## 修改目标

1. 日程、资源和公告页面使用统一高度的标题栏；右侧文字、下拉框和按钮在同一条水平线上，左右两端底边一致。
2. Windows 窗口和任务栏明确使用带 16–256 像素多尺寸图层的 ICO，并在构建时检查必要尺寸，避免退回单张大图缩放。
3. 左侧导航不再长期显示版本号；版本信息只保留在“设置 → 关于”。
4. “网络检查失败”改为准确的“代理连接异常”。它表示系统代理无法访问外部网站，不代表 MAA 自身断网，也不会修改 VPN 或代理。
5. 通知样例与 Agent 实际发送共用同一份标题和正文，测试时手机收到的内容必须与界面预览一致。

## 验证重点

- 深色、浅色和 175% 缩放下检查三个页面标题栏的控件高度与底边。
- 检查 ICO 至少包含 16、24、32、48 和 256 像素图层，并确认 Qt 窗口显式设置该图标。
- 通知测试覆盖普通样例和 MAA 未运行样例，断言预览与发送内容完全相同。
- 运行完整单元测试，并保持后台 Agent 启动路径不导入 PySide6。
