# MAA Agent 优先级路线图

本文件是 P0/P1/P2 文档的索引，具体任务、验收标准和完成状态分别见：

- [ROADMAP_P0.md](ROADMAP_P0.md)：会使监控失去核心意义、泄露密钥或卡死程序的问题。
- [ROADMAP_P1.md](ROADMAP_P1.md)：明显影响长期使用、维护安全或主要交互的问题。
- [ROADMAP_P2.md](ROADMAP_P2.md)：体验、迁移、视觉和探索性功能。

优先级原则：P0 随时打断其他工作；P1 在不破坏现有稳定功能的前提下推进；P2 只有在 P0 清零且 P1 可控时进行。

Kanban 文件保存在 `D:\MAA-Agent-Kanban`。代码行为变化后，同步更新 `AGENTS.md`、对应优先级文档和最新版 Kanban；完成项只移动到最右侧“已完成”栏，不重写用户原有描述。
