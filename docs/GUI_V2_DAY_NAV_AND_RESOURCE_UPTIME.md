# GUI 2.0 日程换日与资源页收口

本轮根据实机反馈补齐三个直接可见的操作细节。生产 Agent、MAA 计划、真实配置和 `app/agent.py` 不改动。

## 日程管理

- 列表第一行是“切换到上一天”，最后一行是“切换到下一天”。
- 每次载入后默认定位到第一条计划，让上一日入口藏在上方；向上滚动一点即可看到。
- 点击换日入口后只读取目标运行日，不拼接多天，也不积压滚轮事件。
- “日程每天从 xx 时 xx 分开始”移动到日程页右上角；点击应用后原子保存并立即按新边界重读当前运行日。

## 提醒设置

- “可用内存低于”增加 MB / GB 单位选择。
- 界面按所选单位输入，保存时统一换算回现有的 MB 配置，保持 Agent 兼容。

## 资源监控

- 删除右上角重复的自然日范围文字。
- 改为显示 Windows 本次启动后已经运行的时长，按天、小时、分钟、秒展示。
- 该内容只读，不增加新的定时读盘；页面可见时用本地计时刷新。

## 验收

- 顶部、底部换日入口可点击，初始定位不会直接露出顶部入口。
- 没有计划的运行日仍能看到两个换日入口。
- MB / GB 往返保存不丢精度，原有 MB 配置继续可读。
- 系统运行时长不会出现负数，页面切走后不做多余刷新。
