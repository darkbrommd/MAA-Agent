# 安全问题报告

## 支持范围

安全修复面向 GitHub Releases 中的最新稳定版本。旧版本可能仍可运行，但不会单独维护安全补丁。

## 如何报告

如果问题可能暴露 Bark Key、DeepSeek Key、GitHub 凭据、本机文件或产生非预期的进程操作，请优先使用仓库的 **Security → Report a vulnerability** 私下报告。如果该入口暂时不可用，可以创建一个不含敏感细节的 Issue，请维护者建立私下沟通方式。

报告中可以包含：

- 受影响版本和环境；
- 最小复现步骤；
- 预期行为与实际行为；
- 已去除密钥、真实路径和个人信息的日志片段。

请不要在公开 Issue、Pull Request 或日志附件中粘贴真实 token、完整 `config.json`、私人路径或未经清理的运行日志。维护者确认问题后，会协调修复和公开说明。

普通功能缺陷、界面问题和文档建议可以直接使用 GitHub Issues。
