当前任务管理器仍可能主要显示为 Python。研究在不破坏无窗口启动、单实例和停止校验的前提下，让任务管理器/任务栏更明确显示 MAA Agent 名称与图标。

验收：不引入打包器安全风险；启停、托盘、PID 校验和跨目录单实例测试全部通过。

### P1-2 Copilot 通知 BAT 去硬编码

三个 Copilot 通知 BAT 仍存在 `_0920`/旧目录硬编码及 `mkdir` 目标不一致。

验收：统一使用 `%~dp0state`，不读取或写入另一安装目录，并补充低成本测试或静态校验。

### P1-3 配置项说明进一步人性化

“全部配置”已有选中项说明，但仍可补充更完整的中文名称/用途映射，避免用户直接面对内部键名。

验收：密钥继续遮罩；未知配置仍可编辑；说明不改变配置类型或值。

### P1-4 长期实机观察

持续观察新版终态报警、时间轴状态和官网公告增量抓取。若出现漏报、重复 Bark、状态反转或 UI 卡死，立即升为 P0。
