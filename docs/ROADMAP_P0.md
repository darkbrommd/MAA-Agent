# P0：核心可靠性与安全

## 当前状态

目前没有已知未解决 P0。

## 任何时候出现都立即升为 P0

1. MAA 明确任务失败却没有 Bark 通知。
2. Bark/DeepSeek/GitHub 密钥进入受跟踪文件或 Git 历史。
3. 时间轴无限加载、主进程/GUI 卡死，或刷新导致核心页面无法使用。
4. 启停脚本误杀无关进程、同时运行两份 Agent，或状态跨安装目录污染。
5. 一次拉取产生大量历史 Bark，或重复通知形成通知风暴。

## P0 验收门槛

- 必须有针对根因的回归测试；不能只加兜底提示。
- 报警修改需同时覆盖“明确失败必报”和“可恢复重试不轰炸”。
- 完整测试通过后才能重启生产 Agent；涉及密钥时推送前扫描当前树和历史。
