# MAA Agent v1.1.1

这个版本整理了公开开发文档和 Windows 辅助脚本，日常启动方式保持不变。

## 改进

- 将公开 `AGENTS.md` 改写为简洁、友好的开发指南，移除固定本机路径、个人网络和维护者专用流程。
- 新增 `CONTRIBUTING.md`，说明公开贡献、测试和隐私边界。
- 本机维护记录改用忽略提交的 `AGENTS.local.md`，不会进入 Git 或 Release。
- 根目录只保留 `MAA-Agent-GUI.bat`；启停、测试、通知预览和兼容脚本统一放入 `tools/windows/`。
- 更新部署、操作和测试文档，移除过时的个人目录与奇怪比喻。

## 兼容性

- 日常用户仍然双击根目录的 `MAA-Agent-GUI.bat`。
- GUI 创建的桌面和开机启动快捷方式不受影响。
- 如果曾手动为旧版辅助 BAT 创建快捷方式，需要改为 `tools/windows/` 下的新路径。

Release 包继续排除用户配置、密钥、日志、状态、备份、虚拟环境和本机维护记录。
