# P2：后续增强与探索

## 当前任务

1. 为未来计划和日程卡片增加克制的动画，但不得造成刷新闪烁、滚动撕裂或额外高占用。
2. 制作可迁移版本与首次启动向导，让用户自行填写路径、Bark key、DeepSeek key，并选择是否启用相关能力。
3. 调研是否能安全地从时间轴反向修改 MAA 定时器；在确认 MAA 热加载与写入安全前，继续保持只读及单次监督例外。
4. 继续优化页面说明、视觉层级和非“控制面板/Excel 表格”观感。
5. 在设置页加入项目地址和必要联系信息，但不要写入私人敏感信息。
6. 评估外部 heartbeat 服务，用于覆盖整机断电、完全断网或 Windows 死机这种本机无法自报的情况。

## 约束

- P2 不得改坏已稳定的 P0/P1 行为。
- 动画和视觉效果必须能在深色/浅色模式下正确显示。
- 可迁移版本仍必须保证密钥不入 Git、日志不泄露、状态目录彼此隔离。
