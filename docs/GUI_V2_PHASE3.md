# GUI 2.0 Phase 3 实施说明

本阶段在 `codex/gui-v2-pyside6` 分支继续迁移设置、首次配置向导和系统托盘。默认 Tk GUI、正在运行的生产 Agent、`app/agent.py`、网络/VPN/代理以及旧版 `D:\MAA-Agent` 均不修改。

## 本阶段目标

1. 新增 PySide6 设置页：左侧二级目录、右侧独立滚动表单、底部固定“放弃更改 / 保存配置”栏，小窗口下保存按钮始终可达。
2. 常规与程序、提醒设置、手机通知与 AI、高级设置、通知测试、关于六个分组按需显示；只使用一个 MAA 时隐藏 MAA2。
3. 所有布尔项使用共享 `ToggleSwitch`；两个位置出现的 `enable_proxy_healthcheck` 使用同一份草稿状态，双向同步。
4. 密钥字段默认遮罩，不写入日志、错误消息或 GUI 状态文件；配置保存采用临时文件替换，并在覆盖前保留 `config.json.bak`。
5. 诊断页明确区分“不发送 Bark 的本地预览”和“会真实推送的通知测试”；真实推送前必须再次确认。
6. 新增 PySide6 首次配置向导：默认一个 MAA、Bark 关闭，可选第二个 MAA；复用既有配置构建语义，不改变 Agent 配置字段。
7. 新增 `QSystemTrayIcon` 生命周期：隐藏到托盘后暂停所有非必要 UI 定时器和绘制；恢复窗口时只异步刷新当前页。独立后台 Agent 不受影响。
8. 验证 `--maa-agent-background` 路径没有导入任何 `PySide6` 模块，并保持既有回归测试全部通过。

## 代码范围

- `app/gui/pages/settings/`：设置页外壳、分组表单和诊断入口。
- `app/gui/services/config_service.py`：后台读取、校验和原子保存配置。
- `app/gui/first_run_wizard.py`：PySide6 首次配置向导。
- `app/gui/tray.py`：托盘菜单和窗口可见性联动。
- `app/gui/main_window.py`、`app/gui/main.py`：懒加载设置页、首次向导与托盘接线。
- `tests/`：配置备份、设置草稿同步、密钥遮罩、单/双实例、向导、托盘暂停和后台零 PySide6 导入测试。

## 不做的事

- 不把新 GUI 切成默认入口，不删除旧 Tk 代码。
- 不启动、停止、替换或重启生产 Agent/GUI。
- 不执行真实 Bark 推送、真实外网诊断或官网抓取测试。
- 不修改 `app/agent.py` 的日志解析、事故、终态、Bark、漏跑等核心业务逻辑。
- 不提交真实 `config.json`、`state/`、`logs/` 或密钥。

## 验收标准

- 设置页缩小窗口后仍能看到固定保存栏；滚轮不会误改未聚焦的下拉框和数值框。
- 切换主题只保存主题，不会顺带提交设置草稿。
- 放弃更改能完整恢复磁盘配置；保存后生成/更新 `.bak`，写入失败不会破坏原文件。
- 单实例看不到 MAA2 字段；切换为双实例后相关字段出现且可保存。
- 两处代理健康检查开关即时同步。
- 密钥默认不可见，且异常文本和日志不包含密钥值。
- 托盘隐藏后页面刷新定时器和进程刷新停止；恢复后当前页恢复，其他页仍不刷新。
- 后台 Agent 启动分支的模块导入列表不包含 `PySide6`。
- 本地完整回归、无头 GUI 测试、175% 缩放专项和远端 Windows CI 通过。

## 实施结果

- 新增六分组设置页，采用左侧二级目录、右侧独立滚动区和固定保存栏；页面仍为懒加载，设置读写在后台完成。
- 新增配置服务：覆盖前生成 `config.json.bak`，临时文件通过 JSON 自校验后再原子替换；失败不会破坏原文件。
- 所有布尔设置统一使用共享动画开关；监控页和高级页的代理健康检查开关即时双向同步。密钥字段默认遮罩，“全部配置”只读视图也会替换敏感值。
- 单实例默认隐藏 MAA2，切成双实例后再显示；保存普通设置会保留已有自定义启动脚本、GUI 配置路径和日志路径，不会静默改回默认路径。
- 诊断区拆成不联网的本地预览和需要二次确认的真实 Bark 测试；本轮测试未提交真实推送。
- 新增 PySide6 首次配置向导，默认一个 MAA、Bark 关闭，可选第二个 MAA；旧配置即使没有 `setup_completed`，只要已有实例映射就不会被误判为首次运行。
- 新增原生系统托盘：关闭窗口改为隐藏到托盘，隐藏后停止页面和进程刷新；恢复时只恢复当前页。退出管理器不会停止独立 Agent。
- 修复快速退出时进程扫描 Worker 的生命周期竞态，退出前等待该服务收尾，避免信号对象先销毁。
- 2026-11-26 本地完整回归 203 项通过，175% GUI 专项 41 项通过，`compileall` 通过，后台分支零 PySide6 导入测试通过。
