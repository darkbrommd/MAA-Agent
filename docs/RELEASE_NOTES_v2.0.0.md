# MAA Agent v2.0.0

这次更新带来了重新设计的桌面管理界面，重点解决旧界面内容拥挤、翻页卡顿和信息不够直观的问题。

## 新界面

- 使用 PySide6 重做总览、日程管理、资源监控、公告中心、日志中心和设置；
- 总览集中展示内存占用、主要程序、未来计划、最近事件与内存趋势；
- 日程按一天查看，默认从凌晨 4 点开始，可直接切换日期并临时跳过或调整一次计划；
- 日程卡片通过颜色区分已结束、即将执行、运行中和失败状态；
- 资源监控支持日期日历、系统运行时间、历史趋势、内存过高记录和高占用程序规则；
- 公告中心改为左右分栏，保留选择和滚动位置，并改善正文整理；
- 日志支持增量读取、筛选、搜索和快捷键调整字号；
- 设置重新分类，所有说明改为更直接的用户用语。

## 流畅度与稳定性

- 日程和异常记录使用虚拟列表，减少大量卡片造成的卡顿；
- 配置、日志、资源历史、公告和进程读取移到后台，避免页面整体冻结；
- 日期切换加入请求版本控制和缓存，快速翻页时不会被旧结果覆盖；
- 隐藏到托盘后暂停不必要的界面刷新；
- 支持 Windows 100%、125%、150% 和 175% 显示缩放；
- Windows 打包会同时检查深浅色 QSS 是否已写入 EXE，缺少主题文件时直接终止构建，避免安装后启动失败。

## 提醒与兼容

- 通知样例与实际测试通知共用同一份文字，手机收到的内容与预览一致；
- “网络检查”明确改为“代理连接检查”，不会修改 VPN 或代理设置；
- 后台 Agent 的日志判断、任务终态、提醒合并和冷却规则保持不变；
- 原有配置、状态和日志继续沿用，升级时不需要重新填写；
- 旧 Tk 界面仍可通过 `--gui-v1` 临时打开，方便遇到问题时回退。

## 升级方法

建议先退出旧版管理器和 Agent，备份原目录后，将压缩包完整解压覆盖。`config/`、`state/` 和 `logs/` 不包含在发布包中，不会覆盖本机数据。
